> 本 skill 由 Claude 命令 `/更新进度` 自动生成，请勿直接编辑。
请根据我最近的 Session 学习记录，更新这个学习主题的进度。

## 步骤

1. 确定主题：以我 @ 的主题主页笔记为准，否则问我要主题名。
2. 读取该主题文件夹下所有 `type: session` 的笔记，以及主题主页和
   学习计划文件（`【主题名】-学习计划.md`，旧主题可能是 `学习计划.md`；如果存在）。
3. 计算进度并更新主题主页 frontmatter：
   - `progress`：已完成的 Session 数 ÷ 学习计划总 Session 数 × 100（取整）。
     没有计划时，按已勾选的章节/主题内可衡量单元估算。
   - `status`：还没开始=待开始；进度在 0-99%=学习中；100%=已完成。
   - `level`：根据「水平拆解」中的里程碑判断我到达的级别（1-5）。
   - `book`：如果这轮学习的教材已拆到 `04-教材分块`，填书名。
4. 同步更新主页的「📝 Session 记录」区块说明（不需要改 Dataview 查询本身），
   并更新「🩹 我的薄弱点」（放在 `<!-- managed: 薄弱点 -->` 之间）：
   合并最近 Session 里「卡住的地方」和测试弱项，去重后列出前 3-5 条。
5. 如果有对应的 `01-全书大纲.md`，根据我在 Session 里学到的章节勾选
   `- [x]`（例如学完第 3 章就把第 3 章那一行改成 `- [x]`），
   并把清单底部的进度数字同步更新。
6. 用中文简短汇报：更新了哪些字段、当前进度百分比、下一节建议学什么。

## 注意

- 只更新上述机器管理的内容（frontmatter 与 managed 标记内的部分），
  不要改动我手写的正文。
- 修改前如果文件里已有内容，先读取再改动，避免覆盖。
