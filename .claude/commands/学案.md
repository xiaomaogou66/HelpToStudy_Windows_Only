请阅读我指定的章节，作为 [topic] 的老师，为我生成**一个整合文件**：
这一章的完整学案 + 本次 Session 学习记录，全部写进**同一个 .md 文件**。

## 第一步：定位章节

- 如果我在对话里 @ 了章节笔记（如 `章节002-概率.md`），直接以它为准；
- 否则告诉我书名和章节号（如"专业课G第 2 章"），你到 `04-教材分块/<书名>/`
  下找到对应分块。注意：**一章可能被切成多个分块**（文件名以同一个章名开头，
  或大纲里同一章对应多个文件），必须把这一章的全部分块都读完，缺一不可；
- 读完后再对照 `01-全书大纲.md` 或分块 frontmatter 的 `chapter` 字段，
  确认没有漏块。
- **对照教材（双书并行，2026-09-12 新增）**：如果主题主页 frontmatter 有 `book_alt`，
  或主页/计划里明确标了「对照教材 / 参考教材」，就**同时读对照教材的对应章节**——
  对照关系先看主题主页或计划里的映射表；没有映射表就按「同一主题的对应小节」自行匹配，
  并在汇报里说明你选了哪几节。对照教材用于：① 英文术语对照 ② 证明与推导 ③ 案例与数据。

## 第二步：确定 Session 编号

- 读取主题文件夹（`03-学习主题/<主题名>/`）下所有 `type: session` 的笔记，
  取最大的 `session` 编号 +1 作为本次编号（没有则从 1 开始）；
- 如果存在学习计划文件（新命名：`【主题名】-学习计划.md`；旧主题可能是
  `学习计划.md`），尽量对照计划把本次学习对到对应的 Session
  （计划里第几个 Session 就填几）。

## 第三步：生成整合文件（学案 + Session，同一个 .md）

文件名：`学案Session-第X章-<章名>.md`

存放位置：有学习主题 → `03-学习主题/<主题名>/`；还没有主题 →
`04-教材分块/<书名>/`。

frontmatter 按 **session 类型**写（这样首页看板和 `/更新进度` 都能识别）：

```
---
type: session
study_guide: true
topic: <主题名或书名>
session: <本次编号>
date: <今天>
hours: 2
status: 待完成
score:
chapter: <章号>
book: <书名>
focus: <本章主题一句话>
---
```

正文结构（学案在前、Session 记录在后）：


## 学案内容要求

1. **覆盖全部知识点**：对照本章所有小节标题、定义、定理、公式、例题和案例，
   一个都不许漏；宁可多列，不要省略。
2. **学术严谨**：定义、定理、公式用准确的书面表述，公式用 LaTeX
   （行内 `$...$`、独立行 `$$...$$`），注明适用条件。
3. **通俗易懂**：在严谨表述之后，尽量给每个知识点配生活化的比喻、
   直觉解释或小例子，让我"先懂意思，再记表述"。
4. **双书对照（当主题存在 `book_alt` 时）**：**每个知识点末尾**加一行
   「🇬🇧 **英文对照**」——英文术语 + 对照教材的小节/定理编号；学案头部同时列出两本书的分块链接。
   ⚠️ 定理编号与术语必须**去原文核对**，绝不凭记忆写；两边术语或记法不同（如补集 $\overline A$ 与 $A^C$、
   公理条数不同导致「有限可加性」一边是公理一边是定理）要**点明差异**。
5. **对照教材的映射表要落进笔记**：生成完在主题主页或计划里留一条映射（章节 ↔ 章节），
   下次生成同一主题的学案就不必重新判断。
6. **教材例题 / 案例一律原题抄录，且抄在原处**：凡引用教材的例题、案例、数据表，**必须把题干、条件、
   数据、选项、表格照抄下来**（建议用引用块 `>` 排版），**不得改写、缩写、换数字或用「同类题」替代**。
   抄在它**所属的那个知识点里**（例题跟着它考的概念走），**不要另开「典型例题」汇总节**。
   解题思路、直觉解释、额外补充才是你写的部分。自编的练习、自测题必须**明确标注「自编（非教材原题）」**，
   不得与教材例题混写；如果实在拿不到原题，就标「教材原题未抄录」并说明原因。
7. **引用必须带「跳转链接」**：凡抄录教材例题 / 习题，都在标题后附一个**指向教材原文的锚点链接**——
   `[[04-教材分块/<书名>/章节NNN-xxx.md#小节标题|跳到教材原文]]`（Obsidian 支持 `文件#标题` 锚点）。
   ⚠️ 标题必须**一字不差**（先在分块里 `grep "^## "` 取准，含全/半角括号、空格差异）。
   同时在学案头部给两份索引：「📖 教材位置索引」（本次覆盖的每一节一个链接）+「🇬🇧 英文位置索引」
   （对照教材的对应小节）。⚠️ 链接里的 `|` **只在表格单元格内**才要转义成 `\|`，正文里用普通 `|`。
8. **指代必须点名（禁止裸用「二者/两者」）**：凡是「…且二者互斥」「两者相等」「它们都…」这类
   代词式表达，**必须把具体对象写出来**（如「$A$ 与 $B-A$ 互斥」而不是「二者互斥」），
   即使教材原文用的是代词。遇到教材里的「二者/两者/它们」时：**先回到前文点名**，
   并在学案里用一条 ⚠️ 写明「这里的「二者」指 $X$ 与 $Y$，不是 $Z$」——歧义会让整道题白读。
9. **折叠内容不能用 HTML `<details>`**（重要！）：Obsidian **不渲染原始 HTML 块里的 LaTeX**，
   用 `<details><summary>…</summary>` 包住的自测题答案会把 $公式$ 变成纯文本。
   ➜ 改用 **可折叠 callout**：`> [!success]- ✅ 答案与提示（点击展开）`，
   后续每一行前面加 `> `（空行写成单独一个 `>`），callout 里的公式、表格、链接都能正常渲染。
   同理，其他需要折叠的段落也用 `> [!类型]-` 这种写法，不用 HTML。

## 保存与汇报

- 如果目标文件已存在（比如同一章重做学案），先读旧版，再决定覆盖还是追加，
  不要无提示地覆盖我手写的内容；
- 章节太长（超过约 6 万字）时不要硬塞：分块生成后合并进同一个文件，保证不遗漏；
- 完成后用中文简短汇报：读了几块、覆盖多少个知识点、Session 编号、
  文件链接；并提示我学完后运行 `/更新进度` 自动更新主页进度。
  有对照教材时，额外说明**对照了哪几节、哪些术语/编号有差异**；

## 注意

- 只读取本章分块、主题主页（以及 `book_alt` 对照教材的对应章节），
  不要读整本书或整个库（省钱原则）；
- 如果我在对话里明确说"只要学案"，可以省略 Session 记录部分；
  默认情况下生成上面的整合文件。
