新学期换课表。我要把学校新导出的 `.ics` 接进 Google 日历，替换掉上一学期的课表。

**总原则：先体检（--dry-run）、再备份、最后才写入；绝不上来就写。**

## 第一步：确定新表文件

- 我给了路径 → 直接用
- 没给 → 自己在这些地方找**最近 7 天修改过**的 `.ics`，列出来让我确认是哪一个：
  - `05-日程安排/_资源/日历/`（**不要**翻 `课表-历史/`，那是旧表）
  - `~/Quark/夸克上传文件/`
  - `~/下载/` 或 `~/Downloads/`
- 候选只有一个时也要念一遍路径再动手；**找不到就问我**

## 第二步：体检（只读，不写入）

```bash
cd <你的库>\05-日程安排\_脚本
./同步日历.bat --dry-run --ics "05-日程安排/_资源/日历/<新表>.ics"
```

读输出里的三行：**任务条数 ｜ 课表条数（从 .ics 展开）｜ 窗口**。

判断三件事：

1. **课表条数是否为 0** → 说明选错文件了（比如拿成了 `学习时段.ics`，它的条目都是 `📚` 开头，
   会被自动过滤）。**停下，回去重选**，不要加 `--allow-empty-ics`。
2. **和现在的数量比**：现在跑 `./同步日历.bat --dry-run`（不带 `--ics`）能拿到当前条数。
   新版**掉了超过一半** → 脚本自己会拒绝写入（安全阀），要重新检查文件。
3. **是不是课表**：看每行标题是不是课程名。顺手列一下课程清单做对比：

```bash
grep -h "^SUMMARY" "05-日程安排/_资源/日历/课表-历史/<旧表>.ics" | sort -u > /tmp/old.txt
grep -h "^SUMMARY" "05-日程安排/_资源/日历/<新表>.ics"      | sort -u > /tmp/new.txt
echo "=== 新增的课"; comm -13 /tmp/old.txt /tmp/new.txt
echo "=== 消失的课"; comm -23 /tmp/old.txt /tmp/new.txt
```

## 第三步：备份旧表 + 换上新课表

学期名按新表第一条课的日期推：**9–1 月 = `YYYY-YYYY+1-1`（上学期）**，**2–7 月 = `YYYY-YYYY-1`（下学期）**。

```bash
cd ~/obsidian_vault/05-日程安排/_资源/日历
mv "课表-当前.ics" "课表-历史/<学期> 课表.ics"      # 旧表进历史（这就是备份）
cp "<新表路径>" "课表-当前.ics"
```

> 旧表**不要删**，`课表-历史/` 就是用来留档对照的。

## 第四步：正式同步

```bash
cd <你的库>\05-日程安排\_脚本
./同步日历.bat
```

期望看到类似：

```
📚 课表：新增 N｜更新 M｜未变 K｜删除过期 J
🧹 清空旧的计划事件：X 条
📤 计划事件：写入 X/X 条
```

- `删除过期` = 上学期那些已经不在新表里的课，被自动清掉 ✅ 这正是换课表该有的效果
- 如果课表数量骤降被拦下：**先回来问我**，不要自己加 `--force-ics`

## 第五步：汇报（中文，简短）

- 新表路径 + 学期名（`YYYY-YYYY-1/2`）
- 课表：新增 / 更新 / 未变 / 删除过期 各多少
- **新增了哪些课 / 消失了哪些课**（用第二步的 comm 结果）
- 旧表备份到哪个文件
- 提醒我：**这个日历里的课表事件是脚本管的**，别手动改（下次同步会按 ics 覆盖）

## 注意

- **永远先 `--dry-run`**；不要为了"省事"跳过体检
- **不要用 `--force-ics` / `--allow-empty-ics`**，除非我明确说用
- 不要动 `00-配置/同步配置.json` 的 `ics_files`（它固定指向 `课表-当前.ics`，换表靠替换文件，不靠改配置）
- 不要碰 `_归档/`（冻结快照）
- 如果新表里混进了 `📚` 开头的自习块（比如拿成了 `全部合并.ics`），脚本会自动过滤——
  自习块由 `/周决策` 管理，不该进课表
- 如果日历里还有**手工导入的旧课表**（不是脚本写的），脚本删不掉它们，
  告诉我去 Google 日历里手动删那个日历/那批事件
