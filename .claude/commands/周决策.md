## 第一步：确定"目标周"是哪一周（用 date 算，别猜）

先看今天是不是**周日**（周决策的固定日）。然后用这个公式算**目标周**——
它是"下一个周一（含今天）所在的那一周"：

```bash
T=$(date +%F)
U=$(date +%u)                          # ISO 星期：1=一 … 7=日
OFF=$(( (8 - U) % 7 ))                 # 周日→1天（明天）；周六→2天；周一→0天（今天）
MON=$(date -d "$T +$OFF days" +%F)
SUN=$(date -d "$MON +6 days" +%F)
YR=$(date -d "$MON" +%G); WK=$(date -d "$MON" +%V)   # ISO 周年/周号
echo "$MON ~ $SUN  →  ${YR}-W${WK}"
```

已实测过的结果（可直接对账）：

| 今天 | 目标周 |
|---|---|
| 2026-09-13（日） | `09-14 ~ 09-20` = **2026-W38** |
| 2026-09-20（日） | `09-21 ~ 09-27` = **2026-W39** |
| 2026-12-31（四） | `2027-01-04 ~ 01-10` = **2027-W01** |

- 路径：`05-日程安排/06-日志/<周号>/<周号>.md`（**一周一个文件夹**：这一周的周决策 +
  `打卡.md` + 7 篇日记都在同一个文件夹里），**周号补两位**（`W39`、`W01`）
- ⚠️ 用 `%G`（ISO 周年）而非 `%Y`，否则跨年会算错
- ⚠️ **不要用 `date -d "next monday"` 带基准日期**，实测不可靠（会算出本周）

### 任务行铁律（必须遵守，否则日历会错）
