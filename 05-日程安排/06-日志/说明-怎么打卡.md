# ✅ 怎么打卡（这个文件夹的用法）

## 一句话

**一周一个文件夹**：`05-日程安排/06-日志/<周号>/`（这一周的**所有东西**都在里面）

| 里面有什么 | 是什么 |
|---|---|
| `<周号>.md`（如 `2026-W38.md`） | **周决策**（本周计划，也是 Google 日历的源） |
| `打卡.md` | **本周打卡页** —— 打卡项的唯一真源 |
| `2026-09-14.md` … `2026-09-20.md` | 周一到周日的**日记**（照常写复盘） |

- 周文件夹由 `_脚本/周文件夹.bat` 建，**`/周决策` 每周日自动跑一次**（它自己连同打卡页一起写进这个文件夹），
  顺带预建周一~周日的 7 篇日记
- 日记用 Obsidian 的「日记：打开今天的日记」打开/新建 —— 日记格式已设成
  `GGGG-[W]WW/YYYY-MM-DD`，所以它会自动落进对应的周文件夹，**不会在 `06-日志/` 根目录另建一份**
- 本篇（`说明-怎么打卡.md`）留在 `06-日志/` 根目录，是这些周文件夹的说明书

## 打卡项为什么不是固定的

打卡页里的条目**不是写死的，是按当天真实课表生成的**。原来固定写「课上 Anki / 地铁泛听 / 今天没崩」，问题是：

- 周三**零深度自习日**、周四没那节课、周日没课 —— 却显示一样的条目，勾了也不知道在勾什么
- 更糟的是，**指定课程这两门课 09-18 才开**，开学前两周根本不存在"课上 Anki"这件事

现在改成**从课表推**：

| 那天课表里有什么 | 就出现什么打卡项 |
|---|---|
| 任意一节课 | `上课 · 课程名 开始–结束`（每节课单独一项） |
| **临时停课**（学校临时通知） | 那天那节课**不计缺勤**：出勤项去掉，改留一条已勾的 `停课 · 课程名 开始–结束` |
| **体育课 / 通识课** | 追加 `课上 Anki 20 分钟`（**只有这两门课挂 Anki**） |
| 专业课A / 专业课B / 体育课 / 通识课 | 追加 `课上泛听` |
| **周六**（有家教 + 地铁往返） | 追加 `地铁泛听 2 小时` |
| 每天 | `今天没崩（崩了也不补课）` |

规则全在 `05-日程安排/00-配置/底线规则.json`，**改规则改那个文件，不要改生成出来的笔记**
（下次生成会按规则重写）。

## 三个地方都能勾，且永远一致

打卡项**只存在一个地方**（本周打卡页 `06-日志/<周号>/打卡.md`），另外两处都是**实时镜像查询**
（Dataview 的 `FROM "05-日程安排/06-日志"` 是递归的，子文件夹里的条目照样查得到）：

| 在哪 | 是什么 | 勾了写回哪 |
|---|---|---|
| **每天那篇日记**（`06-日志/2026-W38/2026-09-14.md`） | 「✅ 今日底线」+「📅 今天要做什么」两块（**按本页 frontmatter 的 `date` 查** → 7 篇各显示各的那天） | 分别写回 打卡页 / 周决策笔记 |
| **首页**「📅 今天」 | 同样两块 | 同上 |
| **本周打卡页**（`06-日志/2026-W38/打卡.md`） | 源文件本身 | 就是它自己 |

> 所以**不用担心"两处打卡不一致"**：日记和首页显示的都只是查询结果，勾的是同一行。
>
> 日记里的两块查的是**那篇日记自己的日期**（`this.date`），所以翻到 `2026-09-18.md`
> 看到的就是 09-18 那天的课和任务；**只有首页「📅 今天」才是按真·今天（`date(today)`）查**。
>
> 每天：`Ctrl+P` → 「日记：打开今天的日记」→ 打开就是今天的底线 + 今天要做什么，顺手勾掉。

## 连续天数怎么算

**当天所有打卡项都勾上**，才算这天"打了卡"；连续多少天就显示多少（首页自动算）。

**计数口径（2026-09-14 定）**：

1. **今天勾完** → 今天计入，数字 **+1**
2. **今天还没勾完** → 数字**不动**（停在昨天为止的连续数），不会因为"今天还没勾"而归零
3. 每天重复：下一天（明天）勾完再 +1，以此类推

> 所以早上打开首页也能看到真实连续数（会标「（截至昨天）」）；只有**昨天和今天都没勾满**才会归零。
> 所以"今天没崩"也在里面 —— 它保证了即使整天崩掉，只要底线勾了，连续记录就不会断。
> 条目的日期前缀 `09-14 ·` 是给 Dataview 认日期用的，**别删**。

## 重跑与换课表

```bash
cd <你的库>\05-日程安排\_脚本
./周文件夹.bat            # 本周：建 06-日志/<周号>/ + 预建 7 篇日记（已存在的不覆盖）
./周文件夹.bat 2026-W39   # 指定周
./打卡.bat                # 本周：写/补齐打卡页（不会清掉已勾的）
./打卡.bat 2026-W39       # 指定周
./打卡.bat --print        # 只看不上盘
```

- **换学期课表后**：先跑 `/课表` 更新课表 → 再跑一次 `./打卡.bat`
  （新课表里指定的那两门课没了，Anki 项也会自动消失）
- 每周日 `/周决策` 会自动跑这两条，生成下一周的文件夹、日记和打卡页
- ⚠️ 别手动搬动/改名 `06-日志/<周号>/` 里的日记文件（`YYYY-MM-DD.md` 是「打开今天的日记」的落点，
  改名或搬走 = Obsidian 找不到，会在根目录重建一份）

## 临时停课了怎么办

一节课临时停课（学校临时通知、老师事假），**不要手改打卡页**（下次生成会重写），按两步走：

1. **让课表知道**：给 `_资源/日历/课表-当前.ics` 里那节课加一条 `EXDATE`（照抄学校的写法）：
   ```
   DTSTART;TZID=Asia/Shanghai:20260909T140000
   DTEND;TZID=Asia/Shanghai:20260909T164500
   EXDATE;TZID=Asia/Shanghai:20260916T140000   ← 加这一行（停课那天）
   SUMMARY:专业课C
   ```
2. **留一条记录**：在 `00-配置/底线规则.json` 的 `停课` 表里写一行 `"2026-09-16": ["专业课C 14:00–16:45"]`

然后跑：`./打卡.bat`（出勤项自动换成一条已勾的 `停课 · 专业课C 14:00–16:45`，**不算缺勤**）
→ `./同步日程.bat`（Google 日历里那节课自动取消）。

> 停课只是**那一天的例外**，课表的周期规则不变；下周照常上。
> 打卡页里的 `停课 · …` 项重跑也不会掉，可以当学期记录留着。
