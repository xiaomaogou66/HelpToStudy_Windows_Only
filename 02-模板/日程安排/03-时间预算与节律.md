# ⏳ 03 · 时间预算与节律（模板）

> 复制成 `05-日程安排/03-时间预算与节律.md` 再填。
> 核心思想：**先给时间，再谈方法**。没预算的目标一定会被课表和突发事件吃掉。

## 一、一学期总预算

| 科目 / 目标 | 每周投入 | 学期总计 | 来源（课？自习？通勤？） |
|---|---|---|---|
| 主线科目 | 5 h | 90 h | 课内 + 晚自习 |
| 次要科目 | 2 h | 36 h | |
| 语言 / 应试 | 6 h | 108 h | 通勤 + 早晨 |
| 合计 | | | **每周上限：__ h（留白 20%）** |

> 每周留白 ≥ 20%：用来吸收突发事件，不是浪费。

## 二、每周节律（周表）

`_脚本/周表.tsv` 的格式：`星期 <TAB> 上午 <TAB> 下午 <TAB> 晚上 <TAB> 放下手机`

```text
周一	09:00–12:00 主线科目（课内）	—	19:00–22:00 主线作业 + 复习	23:30
周二	…	…	…	23:30
```

**怎么定**：
1. 先把**不能动的时间**填进去（课、通勤、睡眠、固定兼职）。
2. 再把**高精力时段**给最难的事（通常是上午）。
3. 每天留一个"零深度自习日"（那天只上课，不安排深度任务）——这是可持续的关键。
4. 每周日留 20–30 分钟做周决策；留白时段必须真的留白。

> 有课表 ics 的人：课直接从课表来，周表只写"课之外的时间块"。

## 三、降级监控（撑不住的时候按这个砍）

| 优先级 | 内容 | 砍到什么程度算"没崩" |
|---|---|---|
| 1（不可砍） | 上课出勤、睡眠、吃饭 | — |
| 2 | 主线科目 | 只做课内作业 |
| 3 | 语言 / 应试 | 只做零意志力底线（寄生在课上/通勤上的那部分） |
| 4（可砍） | 拓展阅读、选修、兴趣 | 全停 |
