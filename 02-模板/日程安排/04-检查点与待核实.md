# 🧷 04 · 检查点与待核实（模板）

> 复制成 `05-日程安排/04-检查点与待核实.md` 再填。
> 这里的东西有**唯一真源**地位：`/周决策` 会读它，两个同步后端也会扫它——
> **带 `📅` 的未勾任务会被自动送进日历**（到点提醒你）。

## 格式约定（别改）

```markdown
- [ ] 检查点内容 📅 2027-01-15 14:00 - 15:00
- [ ] 全天任务就写日期，不写时间：📅 2027-01-31
- [ ] 已完成就把 [ ] 改成 [x]（日历里会加 ✅ 或按配置移除）
```

> ❌ 不要写 `🔁`（重复任务）——重复的事交给课表 ics，不写在这里。
> ❌ 不要在这里写日记式的内容（那是 `06-日志/<周号>/` 的事）。

## 近期检查点（已到期 / 即将到期）

- [ ] 例：确认报名开放时间 📅 2027-01-15

## 待核实（不确定的事，核完就勾掉并写下结论）

- [ ] 例：XX 材料要不要公证？
- [ ] 例：这门课的学分算不算进毕业要求？

## 学期大检查点（每学期末回看一次）

- [ ] 本学期成绩是否守住底线（GPA __）
- [ ] 里程碑是否按计划推进（对比 `00-配置/规划配置.json` 的里程碑）
- [ ] 下学期的课表 / 考试日程是否已就位
